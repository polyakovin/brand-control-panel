Как превратить заметку в пост: от записи к плану

Заметка хранит контекст для автора. Пост должен передать нужную часть этого контекста читателю. Между ними есть несколько понятных редакторских шагов.

Сохраните исходную запись

Не заменяйте заметку первым черновиком. В исходнике остаются детали, формулировки и вопросы, которые могут пригодиться для других материалов. Сделайте отдельный план или копию, а оригинал оставьте доступным.

Для упражнения возьмём учебную запись: «После встречи записал много пунктов. Одни про выбор темы, другие про редактуру. В результате начал писать обо всём сразу. Кажется, сначала надо решить, на какой вопрос отвечаю». В ней уже есть несколько будущих материалов, но их не нужно объединять в один.

Найдите вопрос, на который отвечает запись

Переход от заметки к публикации начинается с вопроса читателя. В примере им может стать «Как выбрать тему из длинной записи после встречи?». Он уже, чем «Как работать с контентом», и задаёт границу: материал не обязан объяснять весь редакционный процесс.

Проверьте вопрос по содержанию исходника. Если заметка его не раскрывает, нужны дополнительные наблюдения или другой угол. Не добавляйте автору опыт и выводы только ради стройного плана.

Сформулируйте ответ одной фразой

Рабочий тезис для нашего примера: «Перед черновиком разделите запись по вопросам и выберите один». Это ещё не заголовок. Это внутренняя опора, с которой можно проверять абзацы.

Попросите себя закончить фразу: «После чтения человек сможет…». Для этого материала ответ будет «выделить одну тему из смешанной заметки». Если в ответе три разных действия, вероятно, стоит сделать серию публикаций.

Тема: работа с заметками. Вопрос: как выбрать одну тему. Тезис: разделить запись по вопросам до написания черновика.

Добавьте пример, который можно проследить

Покажите фрагмент исходной записи и результат разделения. Например, пункт о выборе темы относится к одному вопросу, а пункт о редактуре — к другому. Читатель должен увидеть само действие, а не только услышать совет «структурируйте мысли».

Если исходник связан с клиентом или частной перепиской, подготовьте согласованный фрагмент либо явно обозначенный учебный пример. Не переносите личные сведения в публичную статью вместе с полезным наблюдением.

Соберите короткий план и проверьте границы

План может состоять из пяти пунктов: узнаваемая ситуация, основная мысль, исходный фрагмент, действие на примере, вывод. Теперь подберите начало, которое обещает именно этот путь.

Закончите не общей мотивацией, а повторяемым шагом: «Откройте одну заметку, отметьте разные вопросы и выберите тот, для которого уже есть пример». Если для подтверждения тезиса не хватает материала, оставьте идею в работе. Наличие записи не обязывает публиковать её немедленно.

  • Один вопрос связан с реальной задачей читателя.
  • Тезис отвечает на этот вопрос.
  • Пример позволяет увидеть действие.
  • Вывод не обещает больше, чем показано.
  • Исходная запись сохранена отдельно.
